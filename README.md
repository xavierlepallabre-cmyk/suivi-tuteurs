# Suivi Tuteurs

Application de suivi des apprentis et de prise de rendez-vous avec leurs tuteurs.

## Fonctionnement prévu

- Validation manuelle de tous les rendez-vous par l’enseignant.
- Lien personnel par apprenti.
- Import des données depuis Excel ou CSV et saisie manuelle.
- Disponibilités récurrentes et ponctuelles.
- Prise en compte des déplacements : une visite sur site mobilise généralement une demi-journée.

## État du projet

Dépôt initialisé. La version 0.1 de l’application reste à implémenter.
